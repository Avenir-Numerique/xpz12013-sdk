# DirectoryLineStatus

Line status of the platform.   - Enabled : Active line linked to a platform   - Disabled : No platform linked to the line   - Upcoming : Line associated with a platform, with an effective date in the future 

## Enum

* `ENABLED` (value: `'Enabled'`)

* `DISABLED` (value: `'Disabled'`)

* `UPCOMING` (value: `'Upcoming'`)
